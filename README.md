# 🛒 Front - Lista de Compras

Este é o front-end do projeto **Lista de Compras**, desenvolvido para consumir uma API REST.

## 🚀 Acesse o projeto

👉 https://front-lista-de-compras.vercel.app

## 📦 Sobre o projeto

O sistema permite:

- ✅ Listar itens de compra
- ➕ Adicionar novos itens
- ✏️ Editar itens
- ❌ Remover itens
- ✔️ Marcar como comprado

## 🛠️ Tecnologias utilizadas


- JavaScript

## 🔗 Integração

Este front-end consome uma API de Lista de Compras, realizando operações CRUD (Create, Read, Update, Delete).
